Research Insights & Quantitative Analysis

Abstract Summary

This model traces the complete request path from user-space application through the system call interface, device driver layer, controller, and physical device, then back via the ISR. Results confirm that interrupt-driven I/O yields up to 47% reduction in CPU utilization, 6.7× lower response latency at 80% system load, and 9.1× higher DMA throughput versus PIO at 1 MB transfer size.
